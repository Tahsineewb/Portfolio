How do I get a key?
  1. Open GitHub → New fine-grained token.
  2. Name it Portfolio Studio and pick an expiry date (for example, one year).
  3. Under Repository access, choose Only select repositories → Tahsineewb/Portfolio.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it (it starts with github_pat_) and paste it above.

The key only works on your Portfolio repository. Never share it.
